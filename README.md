# Вычислительная информатика для ММТУ ФПМИ (МФТИ)

В рамках первого года информатики на ММТУ ФПМИ изучается язык С++, включая такие полезные инструменты как wsl, valgrind, git и cmake. Это покрывает необходимый минимум для того, чтобы писать проекты и работать в команде, но незакрытым остается вопрос быстрой и удобной работы с внешними библиотеками. Осенний семестр курса вычислительной информатики состоит из набора лабораторных работ, которые позволяют получить надежные базовые навыки для работы с научными библиотеками с открытым кодом, и проектной деятельности на их основе.
